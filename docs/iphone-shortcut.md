# «Поделиться → local-Spotify» на iPhone

Команда для приложения «Команды» (Shortcuts): в YouTube, YouTube Music или
Safari жмёте «Поделиться» → «В local-Spotify», и ссылка уходит в очередь
загрузок. Панель открывать не нужно.

Готовый файл команды выложить нельзя: Apple подписывает их на устройстве.
Собирается она один раз, минуты за три.

## Что понадобится

* Адрес сервиса в домашней сети, например `http://192.168.1.10:8787`. Узнать
  IP компьютера: `hostname -I` (первое число). Имя `localhost` здесь не
  подойдёт — с телефона это сам телефон.
* Значение `API_TOKEN` из `adder/.env`.
* Телефон в той же Wi-Fi-сети, что и компьютер.

## Сборка

1. Откройте «Команды» → **+** (новая команда). Сверху нажмите на название и
   назовите её **В local-Spotify**.
2. Нажмите **ⓘ** (или стрелку у названия → «Сведения») и включите **Показывать
   в меню «Поделиться»**. В «Типы в меню „Поделиться“» оставьте только
   **URL** и **Текст** — YouTube отдаёт ссылку то одним, то другим.
3. В первой строке команды появится «Получать *URL и Текст* из меню
   „Поделиться“». Нажмите «Если нет входных данных» → **Запросить буфер
   обмена**: так команду можно запустить и вручную, скопировав ссылку.
4. Добавьте действие **«Получить URL-адреса из входных данных»** (Get URLs
   from Input). В нём должен стоять «Входные данные команды». Оно вытащит
   ссылку, даже если YouTube добавил к ней текст.
5. Добавьте действие **«Получить содержимое URL»** (Get Contents of URL):
   * URL: `http://192.168.1.10:8787/api/add` — ваш адрес плюс `/api/add`;
   * нажмите «Показать больше»;
   * **Метод:** `POST`;
   * **Заголовки:** добавьте два:
     * `Authorization` — `Bearer ВАШ_API_TOKEN` (слово Bearer, пробел, токен);
     * `Content-Type` — `application/json`;
   * **Тело запроса:** `JSON`, добавьте поле:
     * тип **Массив**, ключ `links`;
     * внутрь массива добавьте элемент типа **Текст** и вставьте в него
       переменную **URL-адреса** (результат шага 4).
6. Добавьте действие **«Получить значение из словаря»** (Get Dictionary Value):
   ключ `added`, словарь — «Содержимое URL-адреса».
7. Добавьте **«Если»** (If): «Значение словаря» **имеет любое значение**.
   * Внутрь «Если» — **«Показать уведомление»**: `Добавлено в очередь`.
   * В «Иначе» — **«Показать уведомление»**: `Уже есть в фонотеке или
     в очереди`.

Готово. Проверка: откройте ролик в YouTube → «Поделиться» → «Ещё» → «В
local-Spotify». Первый раз iPhone спросит, можно ли команде обращаться
к вашему адресу, — разрешите «Всегда».

## Если не работает

| Что видно | Причина |
| --- | --- |
| «Не удалось подключиться к серверу» | Телефон не в домашней сети, неверный IP или порт, или брандмауэр не пускает: `./deploy/install.sh` открывает порт для локальной сети, если включён `ufw`. |
| Уведомление не появилось, а команда «упала» с 401 | В заголовке `Authorization` нет слова `Bearer` с пробелом или токен скопирован не полностью. |
| 400 «Invalid URL» | Поделились не роликом, а, например, каналом. Принимаются ссылки на видео, Shorts, эфиры и YouTube Music. |
| «Уже есть» на новом треке | Эта ссылка уже в очереди или в фонотеке; упавшую задачу можно повторить кнопкой «Повторить упавшие» в панели. |

Вне дома команда работать не будет: сервис слушает только домашнюю сеть.
